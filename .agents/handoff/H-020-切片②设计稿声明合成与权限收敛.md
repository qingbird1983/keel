# H-020-切片②设计稿声明合成与权限收敛

- 日期：2026-11-03
- 范围：Phase 2 切片②设计稿 `docs/design/phase-2/03-manifest-synthesis.md`（**草稿**，待所有者确认 §10 三项后转定稿）；本轮无实现代码（铁律 1）

## 本轮做了什么

1. **先核六条事实**（03 稿 §2，逐条指向源文件）：F1 五步校验已完整实装但没有任何路径为无报关单插件产出 raw；F2 生产接线的授权策略与 manifest 无关（CLI 用写死的 `p1` 全放行，切片① 的 `manifestAuthRules` 只在测试 rig 用；`wireRun` 没有 `cellEntry` 位 → 承接层插件在 CLI 里跑不起来）；F3 装配编排与运行通道不相交（`AssemblyManager` 只 spawn + 换绑、不 `serveCellChannel`，`cmd-hotswap` 从不起 run → "换绑后可用"是被默认相信的）；F4 授权拒绝本身就是一条完整事实（`subject × action × resource × policyVersion × reason`），**不用先放行就能看清调用面**；F5 只有经通道的调用面可观察（原生 `fetch`/`fs`/SDK 直调一条都不会出现）；F6 边界表 #4/#12 写的"Keel 等价物"在契约与 schema 里没有落点
2. **合成路径定案（两遍观察）**：pass 1 全拒 → 从 `AUTH_DENIED` 得到注册面；pass 2 只放行 pass 1 证明过的下界 → 得到 handler 内的经通道调用面；投影成**候选 + 缺项清单**，候选必须人工审核转正才进五步校验。被否五条记录在案（静态 AST 扫源码 / 观察期先放行 / 无单即拒 / 自动转正 / 替插件编补偿模板）
3. **权限收敛四条口径**：观察 = 拒绝并记录；声明编译是唯一规则源（接进 CLI）；逐次裁决不缓存"曾经成功"；合成的 allow 只到观察到的资源为止（不做通配扩展、去重排序保证候选可 diff）
4. **B6 的接缝方案**：新增 host 层 `wireCell()`（`spawn → serve → alloc` 收敛点，通道随新 manifest 一起绑）+ `BindRequest`/`HotSwapRequest`/`CellFactory` 透传 `cellEntry`；旧插件无迁移面这条如实处置——带 `migration` 声明即在首个 `cell.migrate` 处 `CELL/MIGRATION-MISSING` 并回退（V5 回退主张仍成立）
5. **收口切片① §12 第 5 条（就绪时机）**：三方案对比（A 装载门 + `cell.snapshot` 探测 / B 新 op `cell.activated` / C 事件帧），建议 A——不加 op、不重新解释事件类；代价是改变 Cell 应答语义，需 ADR-0011 + 契约 §3.1/§7 注记
6. **验收面设计**：B 档样本 4 枚（`tierB-01-no-manifest` / `tierB-02-conditional` / `tierB-03-native-io` 专证"合不出即明写缺项" / `tierB-04-upgrade`）+ 测试六份 + CLI 新命令 `keel observe`；§11 落地清单九步，§12 五条限制先登记（含"B2 的硬拦截只覆盖经通道的写口"这条措辞约束）
7. 文档与流水：docs/README 登记 03 稿、CHANGELOG 0.1.028、H-020 归档（裁 H-015）、CONTEXT 重写

## 关键决策（评审锚点）

- **观察不开越权窗口**：合成路径的全部支点来自"拒绝本身就留痕"；任何"先放行再看"的做法都视为违反 I4
- **候选 ≠ 报关单**：不以合成结果替代声明审核（合同 §6 风险 2 原文执行），缺项由作者补，补偿模板尤其不得凭空造
- **B2 的断言强度按可得性写清**：硬拦截断言落在 `tool.provide`（可观察、可拒、两半不写），其它 cap 只断言到"规则按 allow 收窄"，措辞不得升格
