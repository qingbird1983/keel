## 关键实现事实（后续会话别踩）

- **`policies` 装配摘要由调用方合入** `scheduler.start` 的 assembly（`runtime.ts` 既有口径：`{...manifest.record, policies: bindings.map(b=>b.summary)}`，没绑不写字段）；`wirePolicies` 不改 manifest。
- **toolApproval 入参字段名** = `paramsDigest` 但承载明文 params（契约既有形状）；verdict 值域 = `approve/deny`（08 稿草案曾误写 "allow"，已修）。
- **policy 报关单 schema**：permissions/resources/compensation/governance/trust 全强制为空——"拟拦截的能力名"没有声明位，规则只能归代码。
- 策略舱 kill 后：hook 调用走 `HOOK_TIMEOUT_MS=200ms` 超时 → `HOOK_VERDICT{fallback:true}`；策略舱不 attachRun。
- 工具舱每 run 一只（wireCell 先例）；e2e 别复用跨 run。
