## 本轮做了什么

1. **选样**（所有者三条标准：轻量 / 无复杂原生依赖 / 覆盖只读与有副作用）：`dsh-plugin-local-life@0.3.2`（只读算术，10 个 action 一个工具）、`dsh-scrape-webpage@1.0.0`（抓网页 + 关键词统计 + 下载图片 + 运行中审批升级）、`@99galaxy/dsh-turn-notify@1.0.2`（Windows 通知，**主体在浏览器半**）。目录源 = dshmarket + `cdn.jsdelivr.net/npm/dsh-plugin-catalog/index.json`（4380 条）
2. **取回与入库范围**：三枚均按 commit 取回（哈希 = 当日 `main` 头指针，`git ls-remote` 复核），均 MIT。**决定不把他方源码入库**：`pnpm lint` 在三枚上报 82 个 error 是实证（要过只能改他方代码或长期豁免），复现靠 commit 哈希。入库的是 `real-samples/SOURCES.md` + `observed/<pkg>/**`（候选、`gaps.md`、脱敏后的 `observe.txt`、两趟账本）；三条 ignore 写进根 `.gitignore`
3. **观察复跑**：每枚单独 `--out`（**被迫**——三枚入口都叫 `index.js`，候选名由文件名合成，缺省互相覆盖）。结果三枚输出**一字不差**：`state=failed events=9 names=[]` → `validate: ACCEPT` → **EXIT=0**；三份 gaps/candidate md5 相同，账本去时间戳后逐条相同
4. **根因取证**（observe 拿不到，靠单独起舱收 stderr）：`node packages/cordis-adapter/dist/cell-entry.js '<bootstrap>'` → `ERR_MODULE_NOT_FOUND '@deepseek-ai/schemastery'` ×1、`ADAPTER/ENTRY-UNKNOWN` ×2。三枚**没有一枚走到 ctx 面**
5. **一手来源核对**（npm 公开包，只读取证未入库）：cordis 4.0.5 `src/registry.ts` 的插件三形 = `Function(ctx,config)` / `Constructor` / `Object{apply}`，**没有 `activate`**；dsh-tools `DefineToolOptions` = `parameters` / `execute(args, exec)` / `output{schema,render}` / `timeoutMs?` / `isConcurrencySafe?`；`ToolRunContext` = `deferContext(msg)` + **`concludeTurn()`**
6. **两个探针**（临时目录）：记录代理录下 12 个无归属面（入口形状、`inject` 声明、`ctx.provide/get/inject`、`ctx.systemPrompt.section`、`ctx.effect`、`exec` 参数、审批升级、外部 `cordis.patch.yml`、浏览器半…）；真实承接层 ctx 喂同一个 `apply` → `TypeError: ctx.provide is not a function`，turn-notify 则**不抛错不注册安静返回**
7. **文档**：`docs/design/phase-2/08-real-sample-observation.md` 新立（§3 装载层门槛 / §4 面 census / §5 缺陷 D1~D5 / §6 候选行 #16~#26 / §7 方法层 / §8 下一步）+ docs/README 登记 + 合同 §5 **B5 标未通过**并写明原因 + 看板状态行 + 01 稿注记（未增行未改判）+ CHANGELOG 0.1.040
