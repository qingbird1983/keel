# H-022 切片③施工：C 档改法地面与迁移手册首版

- 日期：2026-11-03
- 范围：Phase 2 切片③（锚 **B3**；`docs/design/phase-2/04-c-surface-rewrite.md` §9 清单）

## 本轮做了什么

1. **三个改法面落地（承接层）**：`ctx.model.invoke(reqId,{model,params,estimate})` / `ctx.effects.declare({effectKind,…})`
   / `ctx.ledger.read({types?,seqFrom?,seqTo?})`，全部映射 `CellClient` **既有 op**——零新 op、零新错误码、
   不改契约。旧面（`llm.chat`/`effects.reclaim`/`share.*`/`bus.*`/`config.get`/`net.fetch`）一条都没放行。
   `CORDIS_SURFACE` 增第四桶 `guide`（**不塞进 `mapped`**：那等于把 C 档谎报成 A 档）。
2. **端口不对称显式化**（04 稿 §2 F7）：`buildCordisCtx` 改吃 `CordisPorts = { registry, guide }`；
   宿主端口的三面统一抛 `ADAPTER/PORT-UNSUPPORTED`——诊断端口不假装能跑真链路。
3. **参数与归属校验**：缺 reqId/estimate/effectKind 即拒且**不发帧**；插件试图自带 `effectId`/`compensation`/
   `probeRef` 或 `ledger.read({runId})` 即拒（`ADAPTER/ARGS-REQUIRED`）——内核拥有的量不接受临场指定。
4. **旧插件的补偿表与快照面接进装载**（F5）：`normalizeLegacyExtras` 认 `module.exports.compensations` / `.snapshot`
   （含"函数导出 + 挂属性"形状），坏形状装载期即拒（`ADAPTER/SHAPE-INVALID`），**无导出 = 不登记**（不是登记空表）。
5. **回滚闭环的入口位补齐**：`BuildRuntimeOptions.actionSpec` 增可选 `cellEntry`，rig 的补偿动作舱同样走承接层入口。
6. **三对真进程样本 + B3 主测试**：`tierC-06-self-key/-gateway`、`tierC-08-share/-carry/-peer`、
   `tierC-09-reclaim/-declare`；`tests/cordis-c-surface.test.ts` 7 条断言组（含"未报关 model.adapter → AUTH/DENIED"
   的反向保障）。
7. **迁移手册首版** `docs/design/phase-2/05-migration-handbook.md`：7 条 C 档行全部给 before/after 五段式，
   D 档单列（零例外），末尾一页可勾检查清单。
8. **01 稿六行补实现期注记**（#6/#8/#9/#11/#12/#15，档位未动）；施工中发现并在 04 稿 §10 第 7 条 + 01 稿 #11
   注记登记了一处**字面出入**：`ledger.read` 在可见面矩阵内不需声明，manifest 也无对应字段，"补一张报关单"
   对它没有可补的东西——**不自改判，待所有者复核 B/C**。
