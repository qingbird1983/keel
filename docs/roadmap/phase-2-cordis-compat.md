## 1. 目标

让按旧框架（Cordis）写的存量插件能在 Keel 上运行——**按迁移边界文档逐档承接**：A 档零改动、B 档补声明、C 档给明确改法、D 档硬拒绝。产出可复用的承接层与一份被插件样本验证过的边界清单，把"生态迁移可行"从主张变成有账本证据的事实。

## 2. 范围

### 做

- **承接层实体化**（`packages/cordis-adapter` 从接口级原型扩成运行期承接层）：旧 `ctx.*` 可见面到 Keel 受控等价物的映射、A/B 档自动化、C 档迁移样例、D 档显式拒绝
- **manifest 合成路径**：存量插件无报关单 → 从运行观察收敛权限/资源/补偿声明，产出合成 manifest 后进五步校验（Phase 1 明文不做，本阶段做）
- **验收插件组（合成打底 + 真样本补跑）**：按旧框架典型写法写出 A/B/C/D 四档代表样本，**含"最坏写法"探针**（动态 require、原型链改写、进程级全局 hack）；真实存量插件样本到位后按同一场景复跑，报告注明两次材料性质
- **Phase 1 回填四项全部纳入本阶段**（所有者确认）：
  1. 策略插件 → HookBus 装配链（边界表 #14 的承接前提，也是 B7 的主体）——**已兑现于切片④**（2026-11-03，[ADR-0012](../../adr/ADR-0012-policy-plugin-process-and-hook-op.md)）
  2. 快照物理持久化（跨宿主重启的恢复主张）
  3. 旧 Cell drain 完整语义（收尾期在途动作与轮收束的确切行为）
  4. `model.stream` 流式通道（契约 §4.7）
- **契约修订随 ADR-0008 落地**：`DECISION` 新增依据上界 `throughSeq`，关闭 Phase 1 报告 §3 限制 2；同步契约 §4.1/§5 修订注记与 fixtures 兼容样例
- **迁移手册**：给存量插件方的改写指引，每条 C 档一个 before/after 样例，落 `docs/design/phase-2/`

### 不做（明确排除）

- 观测插件生态与跨 run 账本读取（Phase 3；本阶段只保留既有只读面）
- 新插件生态的声明式替换、能力契约全面替换存量模式（Phase 3）
- 容器 / microVM 隔离后端、分布式与多机（backlog，触发条件见 ADR-0002/0005）
- 静默降级式兼容：**任何映射不到的旧写法不得"凑合跑"**（D 档存在的全部理由；所有者已确认零例外）
- 真实模型凭证托管与安全边界重划（沿用契约 §4.7；如需变更另立 ADR）
- 性能优化（只复采基准，观察承接层与流式通道引入的开销）

## 6. 依赖与风险

- 依赖：Phase 1 全部产出（已完成）；真实存量插件样本的到达时间（不阻塞开工，影响 B1/B5 第二批证据）
- **风险 1：材料自证（处置已定）**。合成组证明的是"我们设想的写法可行"，不是"真实插件可迁移"。缓解：合成组按最坏写法设计；边界表符号回填义务（B5）照跑；报告分两批如实标注证据性质，**不许把合成结果表述为真实存量插件已验证**
- 风险 2：manifest 合成的权限收敛口径。太松 = 越权放行（违反 I4 默认拒绝）；太严 = 存量插件全被拒（迁移失败）。缓解：合成产出"最小可用声明 + 运行观察追加"，越权一律当场拒绝并留痕，不以合成结果替代声明审核
- 风险 3：D 档零例外会遭遇现实压力（#7/#14 正是旧框架最普遍的写法）。缓解：姿态不改，**迁移手册负责给出等价出路**（hook 白名单 + 内核预算/调度能力），把"不能这么写"变成"这么写也能达到目的"
- 风险 4：范围偏大——四项回填 + 承接层并行推进，容易拖成"什么都做"。缓解：按 §7 切片顺序推进，回填项各自绑定明确场景；超范围一律先进 backlog 或另立 ADR
- 风险 5：策略 hook 装配链接入会新增事件写入源，可能冲击 Phase 1 已绿的归因主张。缓解：B8 明确"不退化"，契约 §9 五点作为回归底线
- 估时：**单人 10~14 周量级**（仅量级感知；本阶段规模主要由验收插件组与四项回填驱动，而非承接层代码量）
