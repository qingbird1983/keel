# ADR-0003：模型调用统一经 Keel Core 模型网关

- 状态：定稿
- 日期：2026-11-02
- 关联：briefs/Keel-Design-V0.1.md（本地简报）；ADR-0001；standards/06 §3（凭证存储）
- 取代：无

## 背景

"预算不可旁路"要求 token 用量与费用由内核权威核算。若 Cell 内模型适配器直连外部模型 API，预算与账本只能依赖插件自报——可被绕过、漏报（流式尾部用量、缓存折扣均易漏）。同时模型生态迭代快，把各厂商适配逻辑内置进 Core 会使内核持续膨胀，违背薄内核方向。

## 决策

1. Keel Core 内置**模型网关（Model Gateway）**：Cell 内任何组件发起的 LLM 调用必须经网关，禁止 Cell 直连模型 API。
2. 网关统一执行：授权检查 → 预算扣减（调用前预扣、返回后按权威计量实结）→ 实际调用 → 用量与费用写入执行账本。
3. Cell 内"模型适配器"重定义为**能力插件**：只做提示词组装、协议/格式适配与响应解析；不持有 API 凭证、无直连网络能力。
4. 模型凭证只存 Core 侧，遵循 standards/06 凭证纪律；Cell 侧仅存在凭证引用。
5. 流式响应经网关透传；用量以流结束时网关的权威计量为准。
6. 网关故障 = 发起调用的 Cell 本轮失败，走该 Cell 的故障语义；不级联其他 Cell。

## 理由

- Cell 直连：预算可旁路，直接违反核心不变量，否决。
- 适配器全内置 Core：控制最强但内核膨胀、迭代慢，否决。
- 网关代理是"控制不可旁路"与"模型生态开放"的交点：控制点唯一，适配自由度保留在 Cell 侧插件。

## 后果

- 积极：token/费用权威记账；凭证集中管控；每次模型调用天然留有审计记录。
- 代价：每次调用 +1 本机跳延迟（Phase 1 基准测量并给出预算）；流式透传是性能敏感点；网关成为关键路径组件，其超时与故障语义必须纳入 Core API 契约（A 任务覆盖）。
- 重评条件：延迟基准不可接受 → 研究旁路计量（如网关仅记账不转发）方案，新 ADR。
