# ADR-0006：许可证选用 MIT

- 状态：定稿
- 日期：2026-11-02
- 关联：[ADR-0001](ADR-0001-implementation-stack.md)（插件生态开放性）；根 README"待决策"表（已移除该项）
- 取代：无

## 背景

LICENSE 此前为占位文件（默认保留所有权利），README 待决策表悬置两项之一。Phase 1（MVP 实现）开工前必须落定：首提交、`phase-0.end` tag 与未来对外发布都以有效许可证为前提。

## 决策

1. 采用 **MIT 许可证**，全文替换 LICENSE 占位文件。
2. 版权主体署名 **"Keel Project Contributors"**（占位署名；所有者可随时改为个人/组织署名，MIT 允许，不影响已分发文本的效力）。
3. 年度：2026。

## 理由

- Keel 的定位是承接插件生态的运行底座（ADR-0001），**最大采用度**是核心诉求：MIT 是约束最少、认知成本最低的宽松许可证。
- Apache-2.0 提供显式专利授权与更完整的法律定义，但文本更长；当前无专利敏感的采用方，其收益暂不兑现。
- 专有许可与"承接存量生态、鼓励插件方接入"的目标直接冲突，否决。

## 后果

- 积极：任何方可自由使用/修改/分发（保留版权与许可声明）；生态接入无许可证摩擦。
- 代价/风险：**无显式专利条款**——若未来出现专利敏感的企业采用方或贡献者，需重评（届时可另立 ADR 评估 Apache-2.0 或双许可）。
- 重评条件：出现专利诉讼风险信号、或所有者要求署名/策略变更。
